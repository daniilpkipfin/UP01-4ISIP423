# Система управления сетью детских садов

Проект выполнил Попов Даниил Станиславович, группа 4ИСИП-423, в рамках учебной практики УП.01.01. КИПФИН

Репозиторий: https://github.com/daniilpkipfin/UP01-4ISIP423

## Назначение

WPF-приложение работает с Microsoft SQL Server и базой данных из трех связанных таблиц: `Users`, `Kindergartens`, `Children`.

Реализованы:

- регистрация и авторизация с ролями «Пользователь» и «Администратор»;
- хеширование паролей PBKDF2-SHA256 с солью;
- капча после трех неверных попыток входа;
- смена пароля и проверка вводимых данных;
- поиск, фильтрация и сортировка;
- просмотр данных пользователем;
- добавление, редактирование и каскадное удаление данных администратором;
- диаграмма по детским садам;
- экспорт отображаемых данных в DOCX, PDF и XLSX;
- светлая и темная темы с сохранением выбора;
- подтверждение выхода и удаления данных;
- плейсхолдеры, всплывающие подсказки и сообщения об ошибках.

## Структура

- `KindergartenNetwork.sln` - решение Visual Studio;
- `src/KindergartenApp` - WPF-интерфейс;
- `src/Kindergarten.Core` - модели, проверки, работа с SQL Server и экспорт;
- `db/schema.sql` - создание базы данных, трех таблиц, связей и демонстрационных записей;
- `res` - логотип, значок и шрифт Open Sans.

## Запуск

Требуются Windows, Visual Studio 2022 с компонентом «Разработка классических приложений .NET», .NET 8 SDK, Microsoft SQL Server и SSMS 22.

1. В SSMS 22 подключиться к `localhost\SQLEXPRESS`.
2. Открыть и выполнить `db/schema.sql`.
3. Открыть `KindergartenNetwork.sln` в Visual Studio 2022.
4. Назначить `KindergartenApp` запускаемым проектом и запустить приложение.

Учебные учетные записи:

- администратор: `admin`, пароль `Admin123`;
- пользователь: `parent`, пароль `User123`.
